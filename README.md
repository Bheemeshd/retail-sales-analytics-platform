# Retail Sales Analytics Platform

## Project Overview

This project develops an end-to-end analytics solution for a retail company. It analyses sales performance, customer behaviour, product profitability and marketing effectiveness.

## Business Users

The solution is designed for sales, marketing, finance and senior-management teams.

## Tools

- SQL
- Python and pandas
- Power BI
- Databricks and PySpark
- Git and GitHub

## Business Objectives

- Monitor revenue and profit trends
- Identify high-performing products and categories
- Analyse customer purchasing behaviour
- Measure regional and channel performance
- Evaluate marketing effectiveness
- Support data-driven commercial decisions

## Project Status

Project planning and dataset selection are currently in progress.
